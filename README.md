# WinNotch

A Windows clone of [Boring Notch](https://github.com/TheBoredTeam/boring.notch) — a dynamic island-style notch overlay for the top of your screen.

Built with **WPF / .NET 8 / C#**.

## Features (Target)

- Dynamic notch overlay anchored at the top-center of the screen
- Music controls with album art, progress bar, visualizer
- Calendar integration
- Battery status indicator
- System HUD replacement (volume, brightness)
- File shelf (drag & drop)
- Webcam mirror
- Smooth spring animations
- System tray integration
- Settings panel

## Requirements

- Windows 10 (1903+) or Windows 11
- .NET 8 SDK

## Building

```bash
dotnet build
dotnet run --project src/WinNotch
```
