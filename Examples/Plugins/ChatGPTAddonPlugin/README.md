# ChatGPT Add-on

Adds a prompt scratchpad and quick-launch shortcuts for ChatGPT inside the expanded notch, with support for custom prompt presets and a compact vertical layout.

## Setup

Open `Plugin Manager`, find `ChatGPT Add-on`, click `Configure`, then update the launch URL or quick prompts from the built-in form.

The plugin also stores its values in:

`%AppData%\WinNotch\Plugins\com.winnotch.chatgpt\settings.json`

Manual edits are still supported, but the manager UI is the recommended setup path.
