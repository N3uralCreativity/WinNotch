# Clipboard Stack

`Clipboard Stack` keeps your five most recent clipboard text snippets and file lists inside the expanded WinNotch view.

## What it does

- Watches the Windows clipboard live
- Saves the last `5` copied text snippets or file selections
- Lets you copy any saved item back into the clipboard with one click
- Highlights the most recent item in the stack
- Adapts to light and dark themes
- Includes a compact vertical-friendly layout for side docking

## Notes

- This first release tracks `text` and `file list` clipboard content
- Clipboard history is kept in memory while WinNotch is running
